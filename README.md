# python_airtribe_learning

A personal learning repository for **Python** as part of the [Airtribe](https://airtribe.live) curriculum. This repo contains practice scripts, notes, and examples covering Python fundamentals, data structures, exception handling, and object-oriented programming.

## Prerequisites

- [Python 3](https://www.python.org/downloads/) (3.8 or later recommended)

## Getting Started

Clone the repository and run any script with Python:

```bash
git clone https://github.com/amar-s-08/python_airtribe_learning.git
cd python_airtribe_learning
python demo.py
```

## Project Structure

```
python_airtribe_learning/
├── demo.py                 # Basics: variables, conditionals, loops, functions
├── non_primitive.py        # Data structures: arrays, linked lists, stacks, queues
├── python_ds.py            # Python collections: tuples, sets, dictionaries
├── exception_handling.py   # try/except, custom exceptions, error handling
├── amar.py                 # Additional practice scripts
├── test.py                 # Test and experiment scripts
└── module01/               # Object-Oriented Programming (OOP)
    ├── oop.py              # Classes and objects
    ├── inheritance.py      # Inheritance
    ├── polymorphism.py     # Polymorphism
    ├── abstraction.py      # Abstraction
    └── encapsulation.py    # Encapsulation
```

## Topics Covered

| Topic | File(s) |
|-------|---------|
| Variables, conditionals, loops | `demo.py` |

| Tuples, sets, dictionaries | `python_ds.py` |
| Exception handling | `exception_handling.py` |

## Running Examples

```bash
# Python fundamentals
python demo.py

# Data structures
python python_ds.py
python non_primitive.py

# Exception handling
python exception_handling.py

# OOP examples
python module01/oop.py
python module01/inheritance.py
```
